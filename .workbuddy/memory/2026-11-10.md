# 2026-11-10

## 目录点击区重做：`TocPage` 组件（main_fuyi）

**背景**：上一轮把 main_fuyi 换成《凡人修仙传》45 页，目录按钮还是「32 个手写 rect」的老方案，
结果看起来不对。

**查清的两个真问题**（都不是几何算法错，而是映射错）：
1. **整组错一页 + 左右颠倒**：总目录印在第 1 页（左页），按钮却配在 page 2 + 右页 x(2000~3420)；
   卷一目录印在第 2 页（右页），按钮配在 page 3 + 左页。四组全部 +1 并翻到了对面。
   （`an_li_page_of_group` 与按钮 x 区间都错，y 值和跳转目标其实是对的。）
2. **跳转目标整体 +1**：之前按「书页 = 页脚页码 + 5」算，实际是 **+4**。
   锚点验证：图片 5 = 页脚 01（韩立）、图片 13 = 09（掌天瓶）、图片 44 = 40（结语）。
   所以 4 页之后就是正文，`front_pages` 应为 4（原来是 5），所有 targets 全 −1。

**校准方法（可复用）**：
- 用 Python 扫目录页原图的暗行带 → 得到每页的「首行归一化中心 + 行距」；
- 再从 1600×900 实机截图里检测同样的行带 → 两者归一化值差 <0.001，
  说明 **页面图片和书页在纵向上是 1:1 映射**，行位置可以直接从图片算，不需要人工校准。
- 实测：页1 6 行 f=0.4243 s=0.0644；页2 8 行 f=0.3840 s=0.0540；
  页3 9 行 f=0.3697 s=0.0508；页4 9 行 f=0.3690 s=0.0511。

**新组件**：`scripts/toc_page.gd`（`class_name TocPage extends Control`）
- 一个节点管一页，内部建 `VBoxContainer`，锚点直接设在 (inset_left..1-inset_right, block_top..block_bottom)，
  子按钮 `SIZE_EXPAND_FILL` 均分 → **只需「条目区上下边界 + 行数」就能精确对位**，
  行边界自然压在印刷分隔线上。
- 导出：`page_number` / `block_top` / `block_bottom` / `inset_left/right` /
  `targets`(PackedInt32Array) / `titles`(PackedStringArray) / `show_titles` /
  `title_theme` / `title_font_size` / `highlight_color`。
- `show_titles=false` → 透明点击区（配合已印好的目录图）；`true` → 程序画文字，可整套换主题。
- 场景结构：`UI_Book/Root/Panel/PageAreaLeft|Right`（页框 Rect2，设计坐标）下面挂 4 个 TocPage：
  - 左页 Rect2(540, 199, 1378, 1759)：TocTotal(第1页/6行)、TocVol23(第3页/9行)
  - 右页 Rect2(1920, 199, 1378, 1759)：TocVol1(第2页/8行)、TocVol46(第4页/9行)
- `fanshu2.gd` 改成自动递归扫描 `Panel` 下所有 TocPage（`_collect_toc_pages`），
  删除 `an_li_manager_paths` / `an_li_page_of_group`；`page_chosen` 信号 → `turn_to_page(target, TOTAL, 1.0)`。

**验证**：32 项点击全部跳对（含贴图文件名核对）；每屏只有对应两组可见；两场景冒烟无报错。
场景节点数 61 → 26。

**坑**：
- Godot 4.7 里 `VBoxContainer.separation` **不能赋 int**（赋值报 Invalid assignment），
  要用 `add_theme_constant_override("separation", 0)`。
- 新增 `class_name` 脚本后必须跑一次 `godot --headless --path . --import`，
  否则 `fanshu2.gd` 会报 `Could not find type "TocPage"`（全局类缓存没刷新）。
- `--script` 模式下窗口尺寸不受 project.godot 的 window override 控制，
  会在 2560×1600 屏上开成 1920×2160；必须 `DisplayServer.window_set_size(Vector2i(1600,900))`
  （`root.size = ...` 无效）。抓图校准一律先设窗口尺寸。
